# .github

Default community health files for the **PhaseChangeSoftware** organization.

GitHub uses the files here for any repository in the organization that does not have its own:

| File | Used for |
|---|---|
| [`.github/SECURITY.md`](.github/SECURITY.md) | The security policy shown on a repository's **Security** tab, and how to report a vulnerability |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | The description pre-filled when a pull request is opened |

A repository that has its own copy of either file uses its own instead.

## Changing these files

These files are maintained by the DevOps team. Changes are reviewed in the DevOps team's own
repository first and then copied here, so please don't edit them directly — open an issue
instead.
